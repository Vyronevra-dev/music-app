<h1 style="text-align: center;">Meloflix</h1>

Meloflix is a browser-based music player PWA built with vanilla HTML, CSS, and JavaScript. Users can upload MP3 files from their device and play them through a modern cosmic-purple interface complete with glassmorphism surfaces, a glowing cover art display, gradient play button with pulse animation, active playlist highlighting, full custom range sliders, shuffle, repeat modes, seek and volume controls, and automatic metadata extraction. Installable on desktop and mobile with full offline support via a service worker.
