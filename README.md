<h1 style="text-align: center;">Meloflix</h1>

Meloflix is a browser-based music player PWA built with vanilla HTML, CSS, and JavaScript. Users can upload MP3 files from their device and play them through a clean, Spotify-inspired interface complete with playlist management, shuffle, repeat modes, seek and volume controls, and automatic metadata extraction. Installable on desktop and mobile with full offline support via a service worker.
